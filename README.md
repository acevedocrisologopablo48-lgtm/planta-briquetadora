# PLANTA BRIQUETADORA · SESUVECA · R13

Configurador 3D de implantación: equipos a escala en milímetros, fajas modulares, seis vistas, cotas vinculadas, historial, simulación ilustrativa y exportaciones.

R13 incluye colectora B500 desmontable y regulable, cuerpo inferior/pórtico adaptados como propuesta P y cama con amortiguación propuesta. El punto real de desprendimiento y el comportamiento de la briqueta fresca requieren ensayo; la modificación de cuerpo y apoyos requiere cálculo estructural y revisión del fabricante antes de fabricar o cortar.

Las propuestas se guardan exclusivamente en el navegador. Descargar JSON permite respaldarlas y trasladarlas. Los borradores de visitantes no se publican. R4–R12 siguen disponibles con sus catálogos.

Este repositorio contiene la distribución compilada para GitHub Pages. El código editable, CAD y verificaciones se entregan al propietario por separado. La simulación no calcula producción ni controla equipos físicos.
